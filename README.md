# Amalkumar AK — Portfolio Website

A responsive static portfolio for IT Support, Linux Support and Junior System Administration opportunities.

## Files

- `index.html` — page structure and content
- `style.css` — responsive layout, theme, cards and animations
- `script.js` — mobile navigation, theme toggle, active section and footer year

## Run locally

No build tools or package installation are required.

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

You can also open `index.html` directly in a browser.

## Publish with GitHub Pages

1. Create a new public repository, for example `amalkumar-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub Pages will provide the public website URL after deployment.

## Before publishing

- Verify all project descriptions and your personal contributions.
- Confirm contact details and employment dates.
- Add direct links to project documentation or demos where available.
- Add a downloadable CV only if you want it publicly accessible.

This is a static front-end site. It does not require a backend or collect visitor data.
